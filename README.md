# 🚀 Misi Teknologi Digital: Jom Level Up! (Milo & Bit Edition)

Platform pembelajaran interaktif, gamifikasi, dan simulasi teknologi digital, rangkaian, keselamatan siber, Microsoft Office, Google Drive & AI Prompting untuk murid sekolah.

## 📁 Struktur Fail Projek

```text
├── index.html                  <-- Fail Utama Aplikasi Web (WAJIB)
├── assets/                     <-- Folder Imej Watak 3D & Logo (WAJIB)
│   ├── logo_smkse.png          <-- Logo Rasmi SMKSE
│   ├── milo.jpg
│   ├── bit.jpg
│   └── hero_banner.jpg
├── README.md                   <-- Dokumentasi Projek
└── PANDUAN_PENGGUNAAN.md       <-- Panduan Lengkap Guru & Silibus
```

## 🌐 Cara Mengaktifkan GitHub Pages (Website Percuma)
1. Pergi ke **Settings** repositori GitHub anda.
2. Klik menu **Pages** di sebelah kiri.
3. Di bahagian **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`.
4. Klik **Save**.
5. Tunggu 1-2 minit, pautan laman web anda akan siap (cth: `https://username.github.io/nama-repo/`).
